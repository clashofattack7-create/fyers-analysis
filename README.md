# fyers-analysis

Exploration and probe scripts around the **Fyers API (v3 / SDK)** — material
collected while understanding the Fyers REST API, authentication flows, and
SDK internals.

## Contents

- `_probe*.py` / `_diag*.py` — API endpoint and auth-flow probes
- `_docs*.py` — source extraction from public docs (docs.rs, etc.)
- `sdk/` — local copies of the Fyers `apiv3` wheel and extracted sources
- `login-state*.png`, `dash.png` — UI/screenshot captures (no account data)
- `docs*_out.txt`, `resp_*.html` — captured responses for reference

Public knowledge, educational use only. Broker API credentials are never
committed.
